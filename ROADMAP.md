# Roadmap

- In-cluster ServiceAccount configuration without a named kubeconfig context.
- First-class StatefulSet, DaemonSet, and CronJob diagnostics.
- Stream parsing or a larger configurable cap for clusters exceeding 128 MiB per read.
- Additional credential-pattern fixtures. Log redaction remains best effort.
- Published-artifact verification after the first approved npm stage.
- First GitHub workflow execution after repository creation and import.

Guarded exec, port-forward, and apply preview are planned. Cluster writes and Secret value output remain unsupported.
